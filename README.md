Добро пожаловать в официальный репозиторий **NialCraft**! Это легковесный, оптимизированный 2D-клон Майнкрафта, написанный на Python с использованием графического ядра Tkinter и кастомного бинарного сетевого протокола.

---

## 🚀 Особенности Движка (Features)

*   **⚡ Ультра-оптимизация (No Lag)**: Сервер переведён на неблокирующую архитектуру `select` и бинарные пакеты. Никаких тормозов даже при запуске 5+ копий игры на одном ПК.
*   **🌐 Глобальный мультиплеер**: Поддержка до **50 игроков** одновременно в одной сессии с синхронизацией координат в реальном времени.
*   **💥 Интерактивное меню**: Анимированное появление кнопок интерфейса и эффектный взрыв логотипа на пиксели при клике мышкой.
*   **📦 Облачный режим (Cloud Ready)**: Код сервера адаптирован для деплоя на хостинги (Render, Amvera) с автоматическим подхватом сетевых портов окружения.
*   **🖥️ Fullscreen**: Поддержка погружения в игровой процесс на весь экран по нажатию клавиши `F11`.

---

## 🛠️ Архитектура Проекта (Structure)

*   `main.py` — Оптимизированный клиент игры (интерфейс, анимации, отрисовка сетки 9х9, парсер сетевых доменов).
*   `server.py` — Высокопроизводительное ядро выделенного сервера (бинарный стек, менеджер сущностей, каскадный логгер).
*   `RUN_SERVER.bat` — Скрипт для красивого запуска серверной консоли с симуляцией проверки систем среды.

---

## 🕹️ Как запустить и играть (How to run)

### 1. Запуск локального сервера:
Запустите файл `RUN_SERVER.bat`. Консоль выполнит инициализацию системных компонентов и перейдёт в режим ожидания клиентов:
```bash
Network socket successfully bound to system port 25565. Listening...
```

### 2. Запуск игры:
Откройте терминал в папке с проектом и запустите клиент:
```bash
python main.py
```
В меню выберите **Мультиплеер**, введите адрес (по умолчанию `127.0.0.1:25565`) и нажмите **ПОДКЛЮЧИТЬСЯ**.

### ⌨️ Управление:
*   `W`, `A`, `S`, `D` — Перемещение персонажа по сетке мира.
*   `F11` — Переключение полноэкранного режима.
*   `ЛКМ` — Взрыв логотипа в главном меню.
